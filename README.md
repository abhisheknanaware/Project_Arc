📌 About Project

Project Arc is a modern full-stack web application designed to provide a smooth, responsive, and user-friendly experience. The project focuses on clean UI design, fast performance, and scalable architecture using modern web technologies.

This project demonstrates practical implementation of frontend development, backend integration, database connectivity, authentication, and deployment.

⚙️ Installation & Setup
1. Clone Repository
git clone https://github.com/your-username/project-arc.git
2. Move to Project Folder
cd project-arc
3. Install Dependencies
npm install
4. Setup Environment Variables

Create a .env file and add:

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
▶️ Run Project
Start Development Server
npm run dev
🚀 Deployment

This project is deployed on Vercel.

To deploy manually:

vercel
